# Network Troubleshooting & Fault Diagnosis

## Project Overview

This project focuses on identifying, diagnosing, and resolving common network connectivity problems using Cisco Packet Tracer and Cisco IOS commands.

The lab will simulate network faults, document the symptoms, identify root causes, apply corrective actions, and verify connectivity after each fix.

## Objectives

- Understand a systematic network troubleshooting process.
- Identify IP addressing and subnet mask errors.
- Diagnose incorrect switch VLAN assignments.
- Troubleshoot router interface status.
- Verify switch trunk configuration.
- Use ping and Cisco IOS show commands to isolate faults.
- Document root causes, solutions, and verification results.

## Network Devices

| Device | Purpose |
|---|---|
| Cisco 2911 router (R1) | Gateway and routing |
| Cisco 2960 switch (SW1) | Connects end devices |
| 4 PCs | Connectivity testing |

## Planned Troubleshooting Scenarios

1. Incorrect IP address or subnet mask.
2. Incorrect VLAN assignment on a switch port.
3. Router interface administratively down.
4. Incorrect trunk configuration.
5. Connectivity verification using ping.

## Troubleshooting Method

For each scenario:

1. Observe the connectivity problem.
2. Collect information using diagnostic commands.
3. Identify the likely root cause.
4. Apply a corrective configuration.
5. Retest connectivity.
6. Record the evidence and outcome.
